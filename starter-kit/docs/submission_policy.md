# Draft submission policy

This document records only the shared policy direction that is currently safe
to expose. It is not the final competition rulebook.

## Current direction

- Teams may express interest in one or more tasks.
- Each task will publish a machine-readable submission contract.
- Invalid or malformed outputs will be reported separately from task scores.
- Finalist eligibility is expected to require source code or a reproducible
  notebook so organizers can rerun the system.
