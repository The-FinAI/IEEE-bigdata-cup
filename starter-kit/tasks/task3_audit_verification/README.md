# Task 3 — Financial Audit Verification

Given an SEC-style filing bundle, a target US-GAAP concept, and a reporting
period, a system identifies the reported value and verifies the value implied
by the filing's XBRL calculation network.

The draft schemas retain flexible numeric, unit, period, and evidence fields.
They must be narrowed only after a real filing case has passed legal and
technical review.
