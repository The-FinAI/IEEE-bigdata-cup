# Draft data statement

## Confirmed provenance direction

- Task 1 will use FinChain-derived parameterized financial problems and
  executable traces.
- Tasks 2 and 3 will use HERCULEAN-derived workflows.
- Task 2 is expected to use prices, news, and corporate-filing signals.
- Task 3 is expected to use public SEC/XBRL filings and taxonomy metadata.

## Release requirements

Before any public data is added, the task owner must record:

- source and derivation procedure
- redistribution permission or license
- split construction and leakage controls
- file names, sizes, and SHA-256 checksums
- known limitations and intended use
- removal or correction process
