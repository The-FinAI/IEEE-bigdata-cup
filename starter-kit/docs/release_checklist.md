# Participant-release checklist

The public starter kit may be tagged only when every checked item has an
organizer owner and evidence.

## Shared

- [ ] Stable website, registration, platform, and support links
- [ ] Final schedule with a stated timezone
- [ ] Team, submission, external-resource, and finalist rules
- [ ] Data statement, license, file manifest, and SHA-256 checksums
- [ ] Public/private split and leakage review
- [ ] Versioned validator and scorer images or environments
- [ ] Release gate reports no unresolved markers

## Per task

- [ ] One genuine public input fixture
- [ ] One valid sample submission
- [ ] One intentionally invalid submission
- [ ] Structural validator
- [ ] Official scorer
- [ ] Minimal no-key baseline
- [ ] End-to-end smoke test
- [ ] Hidden-evaluation handoff documented outside the public repository

## Final review

- [ ] No hidden labels, private windows, credentials, or participant data
- [ ] All public commands work in a clean environment
- [ ] Website wording matches this release
- [ ] Two organizers approve the tag and archive checksum
