# Baselines

Baseline code is intentionally absent from this organizer draft.

Each task owner must provide a deterministic, no-key baseline that runs on a
real reviewed development fixture:

- Task 1: a FinChain-compatible answer and trace baseline
- Task 2: a legal toy strategy under the frozen pair and action contract
- Task 3: a filing-bundle-compatible XBRL fact extraction baseline

Prompt-only commercial-API baselines may be added as optional comparisons, but
must not be the only runnable path.
